# Paycheck

A frontend-only payroll calculator built with React, Vite, and Tailwind CSS.

## Architecture

```text
paycheck/
├── src/
│   ├── components/
│   ├── pages/
│   ├── features/
│   ├── engines/
│   ├── data/
│   ├── utils/
│   ├── hooks/
│   ├── storage/
│   └── App.jsx
├── docs/
├── public/
└── README.md
```

## Planned capabilities

- client-side rule tables
- calculation engines
- browser storage for saved data
- local export utilities
- no backend required for the initial phase

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
